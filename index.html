Conhecendo o CSS

O que é CSS?

CSS significa Cascading Style Sheets, ou, em português, folhas de estilo em cascata.

É a liguagem responsável por definir a apresentação visual de um documento HTML.

Como trabalhar com o CSS?

Existem três formas clássicas de colocar o CSS em um arquivo HTML :

  • CSS inline
  • CSS interno
  • CSS externo

Conhecendo o CSS inline

Nessa abordagem, o CSS é colocado diretamente no elemento HTML através de um atributo chamado de style
